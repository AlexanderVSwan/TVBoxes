# TVBoxes
Старые ТВ приставки и эксперименты с armbian

Установка Linux на старые ТВ приставки. Нашёл дома одну, поставил armbian, рассказал - принесли ещё несколько с условием писать что делается.

---
### Об использовании ИИ

Этот репозиторий — результат экспериментов с активным использованием ИИ.  
Большая часть кода (демон для дисплея, скрипты, описания), анализ Device Tree и реверс-инжиниринг драйверов выполнялись с помощью ИИ.  
Все решения и итоговые результаты проверялись и тестировались на реальном железе.
