# X98K (RK3528) TM1628 Display Daemon для Armbian

Легковесный фоновый демон на чистом C (`tm1628d`) для управления встроенным семисегментным дисплеем и статусными иконками ТВ-приставки **X98K** (и совместимых плат на базе SoC **Rockchip RK3528**) под управлением ОС **Armbian / Linux**.

Алгоритм формирования видеобуфера и карта сегментов полностью восстановлены путём реверс-инжиниринга штатного драйвера из оригинального Android-ядра (`vmlinux.elf`: функции `get_dispaly_data`, `tm1628_display_new`, `dig_led_tm1628_ioctl` и `send_8bit`).

---

## ✨ Возможности

* **Минимальная нагрузка на CPU (0.00%):** демон написан на C без внешних зависимостей и удерживает файловые дескрипторы `/sys/class/gpio` открытыми на протяжении всей работы.
* **Ранний старт (`sysinit.target`):** зажигает надпись `LoAd` уже на 2–3 секунде загрузки ядра Linux.
* **Информативный 3-секундный цикл индикации:**
  * **2 секунды:** текущее системное время `ЧЧ:ММ` с мигающим раз в секунду двоеточием.
  * **1 секунда:** температура процессора (°C) и текущая загрузка CPU (%) через двоеточие в формате `TT:LL` (например, `42:08` означает 42 °C и 8% загрузки).
* **Автоматическое управление аппаратными иконками:**
  * `LAN` — активен проводной интерфейс (`eth*`, `end*`, `enp*` в состоянии `up`).
  * `Wi-Fi` — активно беспроводное соединение (`wlan*`, `wlp*`, `wlx*` в состоянии `up`).
  * `USB` — подключен внешний USB-накопитель (`/sys/block/sd*`).
  * `CARD` — установлена внешняя SD-карта (`/sys/block/mmcblk*` с типом `SD`).
* **Автоматическая ночная яркость:** плавный переход на минимальную скважность ШИМ в ночное время (с 22:00 до 08:00), чтобы дисплей не слепил в темноте.
* **Индикация выключения:** при остановке системы или сервиса перехватывает `SIGTERM`/`SIGINT` и оставляет на дисплее надпись ` oFF` на приглушенной яркости.

## 🔧 Аппаратная архитектура и карта памяти (Reverse Engineering)

### 1. Подключение GPIO (Rockchip RK3528)
Связь с контроллером дисплея осуществляется по 3-проводному синхронному последовательному интерфейсу (LSB first):

| Линия TM1628 | Номер GPIO (sysfs) | Смещение в памяти ядра Android | Назначение |
| :--- | :---: | :---: | :--- |
| **CLK** | `gpio146` | `0xAF8` (`#2808`) | Тактовый сигнал |
| **DIO** | `gpio129` | `0xAFC` (`#2812`) | Линия данных |
| **STB** | `gpio142` | `0xB00` (`#2816`) | Строб выбора чипа (Chip Select) |

### 2. Особенность разводки матрицы (Транспонированная схема)
На плате X98K матрица дисплея подключена к контроллеру TM1628 нестандартно (транспонирована на 90 градусов):
* Внутренний буфер состоит из **7 четных байтов** (адреса RAM `0xC0, 0xC2, 0xC4, 0xC6, 0xC8, 0xCA, 0xCC`), а нечетные адреса (`0xC1..0xCD`) всегда заполняются нулями (`0x00`).
* **Каждый четный байт отвечает за один конкретный сегмент (`a..g`) сразу для всех четырёх цифр**, а также за одну статусную иконку.
* **Биты внутри байта** выбирают конкретное знакоместо (позицию цифры от 1 до 4) или иконку.

#### Карта битов внутри каждого четного байта:
| Бит | Маска | Назначение |
| :---: | :---: | :--- |
| **Bit 7** | `0x80` | **Позиция 1** (первая цифра слева) |
| **Bit 6** | `0x40` | **Позиция 2** (вторая цифра) |
| **Bit 5** | `0x20` | **Позиция 3** (третья цифра) |
| **Bit 4** | `0x10` | **Позиция 4** (четвертая цифра справа) |
| **Bit 3** | `0x08` | **Статусная иконка** (зависит от адреса байта, см. таблицу ниже) |
| **Bits 2..0** | `0x07` | Не используются |

#### Карта байтов RAM TM1628 (Сегменты и Иконки):
| Индекс буфера | Смещение в ядре | Адрес RAM TM1628 | Сегмент цифр (биты `7..4`) | Иконка (бит `3` / `0x08`) |
| :---: | :---: | :---: | :---: | :--- |
| `buf[0]` | `0xB50` (`#2896`) | **`0xC0`** | Сегмент **`a`** (верхний) | **USB** |
| `buf[1]` | `0xB54` (`#2900`) | **`0xC2`** | Сегмент **`b`** (верхний правый) | **CARD** |
| `buf[2]` | `0xB58` (`#2904`) | **`0xC4`** | Сегмент **`c`** (нижний правый) | **AM** |
| `buf[3]` | `0xB5C` (`#2908`) | **`0xC6`** | Сегмент **`d`** (нижний) | **PM** |
| `buf[4]` | `0xB60` (`#2912`) | **`0xC8`** | Сегмент **`e`** (нижний левый) | **Двоеточие (`:`)** |
| `buf[5]` | `0xB64` (`#2916`) | **`0xCA`** | Сегмент **`f`** (верхний левый) | **Wi-Fi** |
| `buf[6]` | `0xB68` (`#2920`) | **`0xCC`** | Сегмент **`g`** (центральный) | **LAN (Проводная сеть)** |

### 3. Регулировка яркости и питание
Управление разверткой и ШИМ (PWM) осуществляется отправкой однобайтовой команды `0x80..0x8F`:
* `0x80` — полное отключение развертки дисплея (с сохранением содержимого RAM).
* `0x88` — минимальная яркость (скважность `1/16`, идеально для ночного режима).
* `0x89` — низкая яркость (`2/16`).
* `0x8A` — средняя яркость (`4/16`).
* `0x8B`..`0x8F` — максимальная яркость (`10/16`..`14/16`, визуально на данной плате ступени 4–8 не различаются из-за особенностей ШИМ-контроллера и светофильтра корпуса).

## 🚀 Установка и сборка

### 1. Компиляция демона
Убедитесь, что в системе установлен компилятор `gcc`, и соберите бинарный файл:

```bash
apt-get update && apt-get install -y gcc
gcc -O2 -Wall -s tm1628d.c -o /usr/local/bin/tm1628d
chmod +x /usr/local/bin/tm1628d
```

### 2. Настройка раннего автозапуска через `systemd`
Чтобы дисплей включался максимально рано при старте системы (сразу после инициализации `/sys`), создайте юнит `/etc/systemd/system/tm1628.service` с привязкой к `sysinit.target`:

```ini
[Unit]
Description=X98K TM1628 Front Panel Display Daemon
DefaultDependencies=no
After=systemd-udevd.service sysfs.mount
Before=sysinit.target shutdown.target
Conflicts=shutdown.target

[Service]
Type=simple
ExecStart=/usr/local/bin/tm1628d
Restart=always
RestartSec=2

[Install]
WantedBy=sysinit.target
```

Активируйте и запустите сервис:

```bash
systemctl daemon-reload
systemctl enable tm1628.service
systemctl start tm1628.service
```

## ⚙️ Конфигурация

Все основные параметры вынесены в макросы в начале файла `tm1628d.c` и легко меняются перед сборкой:

```c
#define GPIO_CLK 146
#define GPIO_DIO 129
#define GPIO_STB 142

#define BRIGHTNESS_DAY   0x8F  /* Дневная яркость (0x8B..0x8F) */
#define BRIGHTNESS_NIGHT 0x88  /* Ночная яркость (0x88) */
#define NIGHT_START_HOUR 22    /* Час включения ночного режима (22:00) */
#define NIGHT_END_HOUR   8     /* Час отключения ночного режима (08:00) */
```

## 📂 Структура репозитория

* `tm1628d.c` — исходный код демона на C.
* `tm1628.service` — файл конфигурации сервиса systemd для ранней загрузки.
* `scripts/` — вспомогательные Bash-скрипты для пошагового тестирования сегментов, иконок и уровней яркости через `/sys/class/gpio`.
* `disassembly/` — дампы дизассемблированных функций драйвера из оригинального Android-ядра (`vmlinux.elf`).
