# Tailscale на X98K

## Назначение

На X98K установлен Tailscale, обеспечивающий удалённый доступ к устройству через виртуальную частную сеть (Tailnet).

Используется собственный сервер управления. Его настройка и обслуживание не рассматриваются в этом разделе.

Tailscale позволяет обращаться к X98K из других устройств Tailnet, в том числе подключаться по SSH без необходимости открывать SSH-порт в интернете.

## Сведения об установке

| Параметр | Значение |
|---|---|
| Устройство | X98K |
| Имя узла | `x88pro` |
| ОС | Armbian Linux arm64 |
| Tailscale | `1.104.4` |
| Tailnet IP | `100.64.0.1` |
| Служба | `tailscaled` |

## Подключение к Tailnet

Для подключения используется собственный сервер управления.

Параметр `--login-server` указывает адрес сервера управления, а `--accept-dns=false` запрещает Tailscale изменять системные настройки DNS.

Пример команды:

```bash
tailscale up \
  --login-server=https://<адрес-сервера-управления> \
  --accept-dns=false
```

Вместо заполнителя необходимо указать адрес используемого сервера управления.

Параметр `--accept-dns=false` позволяет сохранить существующую локальную DNS-конфигурацию X98K.

## Проверка подключения

Статус службы:

```bash
systemctl status tailscaled
```

Состояние Tailnet:

```bash
tailscale status
```

Информация об интерфейсе и адресах:

```bash
tailscale ip -4
tailscale ip -6
```

Проверка соединения с другим узлом:

```bash
tailscale ping <IP-адрес-узла>
```

## Удалённый доступ по SSH

После подключения к Tailnet X98K доступен по своему внутреннему адресу:

```bash
ssh root@100.64.0.1
```

SSH также можно использовать по имени узла, если настроено разрешение имён в Tailnet.

## Особенности

- Tailscale работает как системная служба `tailscaled`.
- Подключение к Tailnet сохраняется после перезагрузки устройства.
- DNS-настройки Tailscale отключены через `--accept-dns=false`.
- Соединение между узлами может устанавливаться напрямую, если это позволяют сетевые условия.
- Доступ к X98K по Tailnet не требует публикации SSH-порта в интернете.

## Полезные команды

Посмотреть состояние узлов:

```bash
tailscale status
```

Проверить адрес устройства:

```bash
tailscale ip -4
```

Проверить соединение:

```bash
tailscale ping <IP-адрес-узла>
```

Отключить устройство от Tailnet:

```bash
tailscale down
```

Повторно подключить:

```bash
tailscale up \
  --login-server=https://<адрес-сервера-управления> \
  --accept-dns=false
```
